# Defect-Driven Adaptive Dual-Mode ROV for Tidal-Turbine Inspection

An intelligent underwater Remotely Operated Vehicle (ROV) designed for tidal-turbine inspection, focusing on adaptive positioning, structural defect detection, and operation in challenging underwater environments.

## Project Overview

This project aims to develop an adaptive ROV capable of inspecting underwater tidal-turbine structures while responding to varying environmental conditions. The system integrates mechanical design, hydrodynamic analysis, and AI-based decision-making to improve inspection stability and efficiency.

The proposed system incorporates Reinforcement Learning (RL) for adaptive control and suction-based positioning decisions, alongside CNN-based models for structural defect detection.

## Key Components

### 1. Adaptive Stability Control
Development of an RL-based control model to help maintain ROV stability in high-current underwater environments.

### 2. Intelligent Suction Decision Mechanism
An RL-based decision mechanism to determine when suction-based positioning is required, enabling adaptive operation during inspection.

### 3. Structural Defect Detection
Selection of suitable CNN-based models for automated detection of structural defects in tidal-turbine components.

### 4. Hardware Design and Hydrodynamic Analysis
Evaluation of multiple ROV configurations, selection of an initial hardware design, and drag analysis to assess its hydrodynamic behaviour.
